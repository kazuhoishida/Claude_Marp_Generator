# 入力サンプル

`input/` にはこのくらいラフな状態で置く。
体裁は整えなくてよい。整えるのはこのシステムの仕事。

書いてあるとよいもの:

- 聞き手は誰か
- 何をしてほしいか
- 話したい内容（箇条書き・議事録・メモのままでよい）
- 使いたい画像があればそのパス

---

## 想定する聞き手

社内のエンジニア。デプロイの仕組みは知っているが、
今回入れ替えたビルドキャッシュの中身は知らない。

## してほしいこと

新しいキャッシュ設定を各自のリポジトリにも入れてもらう。

## 話したいこと

- CIのビルドが遅い。1回12分かかっていて、1日30回まわすと6時間
- 原因は依存関係のインストールを毎回やっていること
- 依存関係のキャッシュを入れた
  - lockfileのハッシュをキーにする
  - キーが変わらなければ復元、変わればインストールして保存し直す
- 結果、12分 → 3分になった
  - キャッシュヒット時。ミス時は13分（保存のぶん少し増える）
- 導入方法
  - `.github/workflows/ci.yml` に actions/cache のステップを足すだけ
  - キーは `deps-${{ hashFiles('**/package-lock.json') }}`
- 注意
  - キャッシュはブランチをまたいで共有される。デフォルトブランチのものが使える
  - 7日間アクセスが無いと消える
  - 壊れたと思ったらキー文字列の頭に `v2-` などを足して捨てる

## 次にしてほしいこと

自分のリポジトリの ci.yml に同じステップを足す。
分からなければ #dev-infra で聞いてほしい。
