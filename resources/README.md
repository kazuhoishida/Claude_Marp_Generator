# resources

スライドを作るときに参照する既存資料を置く。

- 過去に書いた記事・ブログ
- 以前作ったスライド
- 仕様書・議事録・調査メモ
- 用語集や表記ゆれの基準

エージェントはスライド作成時にここを見る。原稿（`input/`）に
書かれていない背景情報を補うのが目的。

ただし**ここにある情報を勝手にスライドへ混ぜない**。
原稿に無い事実を足すときは、その旨を報告する。

ファイル名は内容が分かるものにする。日付があるものは頭に付ける。

```
20260701_設計レビュー議事録.md
build-cache-調査メモ.md
過去スライド_20260520_CI改善.pdf
```
